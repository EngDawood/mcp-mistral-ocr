What it can do

Six tools covering every OCR use case — PDF, image, tables, structured extraction, and audio.

📄
mistral_ocr_process_url
Process PDF from URL
Download and OCR any public PDF. Get plain text or markdown with header/footer control.
📷
mistral_ocr_process_image
Image OCR
Extract text from PNG, JPG, and other images via URL or base64 encoded data.
📁
mistral_ocr_extract_structured
Structured Extraction
Provide a JSON schema and get back structured data matching your exact fields.
📊
mistral_ocr_extract_tables
Table Extraction
Pull tables from documents as clean HTML or markdown — ready to use.
🧹
mistral_ocr_clean_markdown
Clean Markdown
Remove repetitive headers and footers from academic papers and reports.
🎙
CLI: Audio Transcription
Audio → Text
Transcribe mp3, wav, m4a, ogg, flac, and more using Voxtral mini via the CLI.
// api reference

Use with curl

All tools are available over HTTP. Pass your Mistral API key as a query param or env secret.

Endpoints

POST
/mcp
MCP SSE transport — for AI agents & Claude Desktop
POST
/?apiKey=YOUR_KEY
HTTP endpoint with user-supplied Mistral API key
GET
/
Health check & server info

Parameters (process_url)

ParamTypeDescription
url requiredstringHTTPS URL to a PDF
output_format optionaltext|markdownDefault: text
pages optionalstringe.g. "1,5-10"
include_images optionalbooleanReturn image metadata
clean_output optionalbooleanRemove repetitive content

Examples

bash
curl -X POST "https://mcp-mistral-ocr.engdawood.workers.dev/?apiKey=KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "mistral_ocr_process_url",
    "url": "https://example.com/doc.pdf",
    "output_format": "markdown"
  }'
javascript
const res = await fetch(
  `https://mcp-mistral-ocr.engdawood.workers.dev/?apiKey=${KEY}`,
  { method: 'POST', headers: {'Content-Type':'application/json'},
    body: JSON.stringify({ tool: 'mistral_ocr_process_url', url: '...' }) }
);
const {content} = await res.json();
python
import requests
r = requests.post(
  f"https://mcp-mistral-ocr.engdawood.workers.dev/?apiKey={KEY}",
  json={"tool":"mistral_ocr_process_url","url":"..."}
)
print(r.json()["content"])

Use with Claude Desktop

Add this to your claude_desktop_config.json

json — via npx
{
  "mcpServers": {
    "mistral_ocr_mcp": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "mistral-ocr-mcp"],
      "env": { "MISTRAL_API_KEY": "your-key" }
    }
  }
}
json — remote worker
{
  "mcpServers": {
    "mistral_ocr_remote": {
      "type": "sse",
      "url": "https://mcp-mistral-ocr.engdawood.workers.dev/mcp",
      "headers": { "Authorization": "Bearer YOUR_AUTH_KEY" }
    }
  }
}

Deploy to Cloudflare

Get a public HTTPS endpoint in under 2 minutes.

1
Clone & install
Clone the repo and run npm install
2
Set your API key
npx wrangler secret put MISTRAL_API_KEY
3
Deploy
npx wrangler deploy — live URL instantly.
4
(Optional) Set auth key
npx wrangler secret put MCP_AUTH_KEY
bash
npm install
npx wrangler secret put MISTRAL_API_KEY
npx wrangler secret put MCP_AUTH_KEY  # optional
npx wrangler deploy
# Your URL: https://mcp-mistral-ocr.engdawood.workers.dev
